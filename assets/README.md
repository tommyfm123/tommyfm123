## Portfolio tools and profile links

The portfolio's `app/components/stack-section.tsx` is the reference for the AI and tool selection. Cursor, Claude Code, Gemini, v0, GitHub, Notion, Figma and AWS marks are unchanged assets from `tommyfm123/portfolio-tomas-2025/public/logossoft`. Codex uses the OpenAI mark already present in the portfolio component. Its paths are retained unchanged. React Native uses the original React mark; MongoDB and LinkedIn use Devicon originals. The portfolio link uses the unchanged `public/icon.png` favicon.

Original tool SVGs are retained in `tools/originals`; original link marks are retained in `links/originals`. Display containers retain the original marks, including v0's white mark on a dark surface. The centered headline and focus text follow the user's requested emphasis on harness engineering, AI agents and AI workflows. LinkedIn's profile text could not be read because its public URL requires sign-in.
